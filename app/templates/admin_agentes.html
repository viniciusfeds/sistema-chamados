Agente local

Programa instalado num computador da unidade que testa os equipamentos pela rede interna e envia tudo ao {{ config.SISTEMA_NOME }}. Só faz conexão de saída: não precisa liberar portas nem redirecionar nada no roteador.
{% if servidor.startswith('http://localhost') or servidor.startswith('http://127.') or servidor.startswith('http://192.168.') or servidor.startswith('http://10.') %}
O agente vai falar com {{ servidor }}, que só funciona na rede local. Para as unidades, defina o Endereço público do sistema (ex.: https://chamados.tecnosit.com.br) antes de baixar.
{% endif %}

Download

🪟 Windows

Windows 10/11 ou Server. Ideal para o PC da recepção.
  1. Baixe e extraia o .zip no computador da unidade.
  2. Dois cliques em Instalar.bat (confirme como administrador).
  3. Digite a chave de ativação do cliente e escolha a unidade.
⬇ Baixar para Windows

🐧 Linux

Mini PC, Raspberry Pi ou servidor (systemd, Python 3).
  1. Copie e extraia o .zip no equipamento.
  2. Rode sudo sh instalar.sh.
  3. Digite a chave de ativação do cliente e escolha a unidade.
⬇ Baixar para Linux

Versão {{ versao }} · conecta em {{ servidor }}. A chave de ativação de cada cliente fica em Administração → Clientes. Depois de instalado, marque os equipamentos com Testar pelo: Agente local no inventário.
